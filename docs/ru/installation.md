# Установка и CLI

[Оглавление](../../README.ru.md) · [English](../en/installation.md)

Нужен Python 3.11 или новее. В каталоге исходников выполните:

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -e .
ha-entity-migrations --version
```

Версия первого релиза — 0.1.0. Зависимостей во время работы нет; для сборки pip
может загрузить backend. Для полностью автономной установки заранее подготовьте
wheel и зависимости сборки. Не устанавливайте пакет в системный Python ради
исправления неверного PATH.

Две команды, язык задаётся до имени команды:

```sh
ha-entity-migrations --lang ru fingerprint examples/domain-change/snapshot.json
ha-entity-migrations --lang ru plan --manifest examples/domain-change/manifest.json --snapshot examples/domain-change/snapshot.json --root examples/domain-change --format text
```

`fingerprint` возвращает SHA-256 точных байтов файла, не проверяя его JSON.
Пробелы и переводы строк влияют на результат. Обновляйте отпечаток в манифесте
только после проверки изменившегося исходника, а не для подавления ошибки.

`plan` читает JSON-манифест, нормализованный JSON-снимок и только явно названные
в `sources` файлы относительно `--root`. Рекурсивного поиска или подключения к
HA нет. По умолчанию выводится JSON; `--format text` включает текстовый отчёт.
`--lang en|ru|de|es` меняет пояснения, но не ключи JSON и коды диагностики.
Справка доступна через `--help` у программы и каждой команды.

Коды выхода: **0** — готово к проверке в поддержанном объёме; **2** — неверные
аргументы, схема, нечитаемый файл или превышение лимита; **3** — корректно
прочитанные данные породили конфликт или неразрешённую ссылку. Ошибки входных
файлов возвращают JSON `status: invalid` в stdout; ошибки аргументов — справку
в stderr. Команда fingerprint выводит только хеш.

Храните реальные входные файлы и отчёты приватно. Программа сама ничего не
записывает; перенаправление stdout в файл — действие оператора. Отчёт может
содержать имена устройств и пути. Удаление пакета:
`python3 -m pip uninstall ha-entity-migrations`.
