# Диагностика

[Установка](installation.md) · [Ограничения](limitations.md) · [English](../en/troubleshooting.md)

**Команда не найдена:** активируйте окружение установки. Проверьте
`python3 -m ha_entity_migrations --version`. Не путайте несколько Python.

**Exit 2 / schema_invalid:** сравните поля с примером и моделью. Неизвестные
поля отклоняются. Версия — число 1, канал — строка. У action нужен указатель
на сервис. Снимок содержит entities, манифест — assignments и consumers.

**Exit 2 / duplicate_source:** два имени обозначают один физический файл.
Оставьте в `sources` одно каноническое имя и обновите поля `file` у потребителей.
Уберите повторные разделители, жёсткие ссылки и варианты регистра; не задавайте
псевдониму отдельную политику. Разные файлы с одинаковыми байтами допустимы.

**stale_snapshot / stale_source:** разберите отличие от согласованной версии,
затем при необходимости обновите отпечаток. Даже пробелы меняют SHA-256.
Нельзя выбирать старый файл только ради совпадения хеша.

**source_collision / destination_collision:** повторяется физический канал,
роль либо entity ID. При обмене ролями опишите обе стороны и проверьте, что
неизменённый канал не удерживает нужный ID.

**role_not_allowed / capability_missing:** сценарий попадает на неподходящую
нагрузку или теряет функцию. Проверьте, должен ли он следовать роли или железу.
Не добавляйте несуществующее диммирование и не расширяйте разрешения вслепую.

**missing_policy / unmodeled_reference:** сначала подтвердите назначение
ссылки, затем добавьте декларацию. Если файл содержит только историю, можно
явно исключить его из области текущей миграции, документируя исключение;
нельзя выдавать частичный охват за весь HA.

**dynamic_reference / embedded_reference / indirect_target:** нужна ручная
проверка шаблона либо косвенной цели. Разрешён явный нормализованный JSON,
эквивалентность которого проверил оператор. Шаблоны здесь не выполняются.

**display_domain_review / service_data_review / mixed_action_targets:**
проверьте функции карточки, параметры и группы целей. Разделение действия
разных доменов — отдельное изменение исходника, не простая замена сервиса.

**retire_scope_mixed / overlapping_edits:** выберите цельный устаревший объект
без посторонних ссылок. Не удаляйте одно поле entity_id: это может расширить
действие или сделать конфигурацию недопустимой. Проверьте оставшийся контейнер.

**unsupported_source:** YAML и другие форматы не пропускаются молча. Явная
JSON-копия может помочь анализу, но её нужно сопоставить с оригиналом до правки.

В отчёт об ошибке включайте только минимальный вымышленный пример, версии
программы/Python, код выхода и диагностику. Не прикладывайте реальные ключи,
полный домашний экспорт или журналы с идентификаторами.
