# Tiếng Việt documentation

Tiếng Việt editions of the six English guides. Each page links to the other languages.

- [Cài đặt và CLI](installation.md) — install the package and use the fingerprint and plan commands.
- [Mô hình đầu vào](model.md) — strict JSON manifest and snapshot schema, including entity and policy fields.
- [Ví dụ có giải thích](examples.md) — worked synthetic role-swap, domain-change and blocked-template cases.
- [Kiến trúc và hợp đồng báo cáo](architecture.md) — module layout, the conservative scanner and the deterministic report contract.
- [Khắc phục sự cố](troubleshooting.md) — exit codes, schema errors, stale fingerprints and other failure diagnoses.
- [Giới hạn và ranh giới xem xét](limitations.md) — what a plan cannot see, unsupported YAML and the review duties left to the operator.
