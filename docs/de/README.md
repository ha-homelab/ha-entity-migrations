# Deutsch documentation

Deutsch editions of the six English guides. Each page links to the other languages.

- [Installation und CLI](installation.md) — install the package and use the fingerprint and plan commands.
- [Eingabemodell](model.md) — strict JSON manifest and snapshot schema, including entity and policy fields.
- [Durchgearbeitete Beispiele](examples.md) — worked synthetic role-swap, domain-change and blocked-template cases.
- [Architektur und Berichtsvertrag](architecture.md) — module layout, the conservative scanner and the deterministic report contract.
- [Fehlerbehebung](troubleshooting.md) — exit codes, schema errors, stale fingerprints and other failure diagnoses.
- [Einschränkungen und Prüfgrenzen](limitations.md) — what a plan cannot see, unsupported YAML and the review duties left to the operator.
